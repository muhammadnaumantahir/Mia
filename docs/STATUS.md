## Owner-confirmed core product priorities (2026-11-19)

Mia's three co-equal core priorities are now **persistent identity and memory**, **autonomous digital life and proactive initiative**, and **self-programming with governed evolution**. This is a product-level direction implemented through the original ten SPS layers; it does not add an eleventh layer.

**Implementation truth:** The repository has persistent conversation storage and a growing memory/knowledge foundation, but contextual retrieval now runs on every chat request (2026-11-19: lexical FTS5 over knowledge and all past messages, provenance-labelled, bounded, local-only unless the owner opts in); owner-managed structured decision/goal/episode/project/entity records with provenance, corrections and competing-claim surfacing now feed the same retrieval (owner API only); automatic extraction, consolidation, owner-editable identity and semantic retrieval are still missing. The task runtime has limited opt-in background dispatch for already-approved read-only system-inspection tools, but it does not yet provide a curiosity engine, independent research lifecycle, reflection loop or proactive social/conversation initiation. Self-programming has candidate storage, Docker validation and owner-gated promotion/rollback records, but safe permissioned plugin activation remains incomplete. The proactive digital-companion architecture is now specified in [DIGITAL_PERSON_RUNTIME.md](architecture/DIGITAL_PERSON_RUNTIME.md); this design must not be mistaken for implemented functionality.

## Not complete

Mia is not yet a finished personal assistant or proactive digital companion. The autonomous digital-life cycle (curiosity backlog, independent exploration, reflection, proactive conversation initiation and notification policy) is not implemented. Long-term memory retrieval/consolidation and full continuity across model/provider changes remain incomplete. General multi-step autonomous execution, verified OS-level sandbox, a permission broker for activation of permissioned capabilities on the target PC, always-on wake word, real desktop interaction and the actual 30-day experiment also remain incomplete.

No Day 0 or daily growth data may be fabricated. Daily snapshots require local host verification and are not auto-filled when Mia is offline.
