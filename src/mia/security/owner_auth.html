Owner passkey

Mia uses a passkey with user verification for high-risk approvals, computer actions and owner administration. The authenticator must verify your presence (for example Windows Hello, a device PIN/biometric, or a security key). Mia receives only the public credential and signed assertions; your private key remains with the authenticator.

Use the localhost address

Browser passkeys are bound to the relying-party origin localhost. Open this page at http://localhost:PORT/owner-auth, using the same port as Mia. The IP address 127.0.0.1 is not the passkey origin for this setup.

Register the first owner passkey

On the Mia host, install the optional package and generate a short-lived one-time code in a local terminal:

python -m pip install -e ".[owner-auth]"
mia-owner-auth bootstrap

The code is valid for five minutes and can be used once. Do not share it or paste it into a third-party tool.

Authenticate

Use your registered passkey. Mia requires user verification for every authentication ceremony.

Owner session active

This browser has an authenticated owner session.

Add another passkey

Your current authenticated owner session is required before Mia will accept another credential.

Owner sessions are held in an HttpOnly, SameSite=Strict cookie for up to eight hours. Signing out revokes the server-side session. Stop-all, pause and revocation controls remain available even when a passkey session is not active.
