Companion Devices

Pair a Windows companion using a one-time code. Device credentials are separate from owner authority. Each device receives only the scopes you select; revocation immediately invalidates its sessions. First-time pairing and administration remain local to Mia.

Local trust boundary

This page and the pairing endpoints are restricted to Mia's loopback/Origin boundary, but the owner browser/API session is not yet cryptographically authenticated. A different process running as the same local user may still reach owner administration APIs until MIA-COMP-04-OWNER is complete. Do not treat this page as protection against malware or another untrusted local process.

Create a one-time pairing code

Shown once · expires

On the Windows device, run mia-companion pair --server http://127.0.0.1:8765 --name "My Windows PC", then enter this code when prompted. Install .[companion] first. Do not send the code to anyone or paste it into a third-party service.

Windows companion commands

Run these in the Windows user's terminal after installing the optional companion extra:

pip install -e ".[companion]"
mia-companion status
mia-companion set-server --url https://mia.example.com --confirm
mia-companion install --confirm
mia-companion start
mia-companion stop
mia-companion uninstall --confirm

The Scheduled Task is installed only when you explicitly confirm it. It runs at the current user's logon with Limited privilege. The companion opens outbound connections only; it does not listen for inbound commands.
